# MyLove's Essentials — Store

## Stack
React + Vite + Supabase + Netlify.

## Setup
1. Install Node.js.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Put your NEW Supabase publishable/anon key in `.env`. Never put a service-role key in the frontend.
5. Run `npm run dev`.
6. Build with `npm run build`.

## Supabase
The database schema/policies already prepared for this project should be run in the new Supabase project's SQL Editor.
